# Kept-format fixtures

What a workspace keeps in `Kept/`, as an earlier build wrote it: `v4/history.log`
is upstream's own fixture — the log its build of workspace version 4 wrote,
pinned at the length and hash `keptFormatVersion.test.ts` names — copied as it
is, since the web writes the log in upstream's format record for record. Never
rewritten: a later build must read it as it is.
