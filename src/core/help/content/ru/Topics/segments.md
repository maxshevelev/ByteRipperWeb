# Сегменты: как разрезать дамп на части

> Отметьте швы образа, а потом сохраните каждый сегмент отдельным файлом.

Сегментация разбивает файл панели на **сегменты**: непрерывные, непересекающиеся, всегда покрывающие файл целиком. Любой открытый файл начинается как один сегмент — он сам.

Сегменты не меняют байты. Это способ *читать* файл; пишет только явное сохранение.

## Как сделать разрез

- Щёлкните правой кнопкой в дампе и выберите **Разрезать здесь по «адресу»** — быстрый путь, по курсору.
- **Сегменты ▸ Разрезать здесь…**, чтобы вместо этого ввести адрес.
- **Сегменты ▸ Объединить** убирает разрез перед сегментом, в котором стоит курсор, сливая его с соседом.
- **Сегменты ▸ Сегменты…** открывает список: все сегменты, их диапазоны, имена и кнопки, действующие на всё сразу.

Сегменты подписаны **S0, S1, S2 …** в порядке файла и перенумеровываются сами, когда разрез добавлен или убран. Имя, которое вы дали сегменту, остаётся с ним, каким бы ни стал его номер.

## Как сохранить части

Форма сегментов умеет **сохранить все сегменты отдельными файлами** одной командой. Вместе с [[topic:join-duplicate|Дописать файл в конец…]] это и есть рабочий приём для платы с двумя чипами памяти:

1. Прочитайте оба чипа — получатся два файла.
2. Откройте один и **допишите в конец** второй — теперь весь BIOS один образ.
3. Работайте с ним: сравнивайте, ищите, правьте, открывайте [[topic:tool-uefi|панель UEFI]].
4. Шов, на котором файлы встретились, — уже готовый разрез, поэтому **Сохранить всё отдельными файлами** вернёт вам две половины, готовые к записи каждая в свой чип.

! Разрез едет вместе с байтами: вставьте данные перед ним — разрез сдвинется. [[topic:bookmarks|Закладка]] делает наоборот — остаётся на своём адресе. Разрез — это «край вот этого региона», закладка — «вот этот адрес».

Сегменты живут, пока открыт файл.
