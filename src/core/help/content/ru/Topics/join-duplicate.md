# Объединение и дублирование

> Объединение дампов двух чипов памяти в один образ и дублирование образа для правки копии.

## Объединение: дампы двух чипов SPI в один образ

На платах, прошивка которых размещена в двух чипах памяти, читаются оба чипа и открывается первый файл. Далее:

- **Файл ▸ Дописать файл в конец…** — байты выбранного файла встают после содержимого панели.
- **Файл ▸ Вставить файл в начало…** — встают перед ним.

Вся прошивка после этого представляет собой один образ, с которым штатно работают сравнение, поиск и [[topic:tool-uefi|инструмент UEFI]], рассчитанный на один непрерывный образ.

Граница записана как разрез [[topic:segments|сегмента]], поэтому команда **Сохранить всё отдельными файлами** возвращает обе половины ровно по этой границе — в выбранную папку там, где браузер это позволяет, и ZIP-архивом там, где нет.

Из этого следуют два свойства результата:

- **У объединённого документа нет собственного файла.** Он безымянный, поэтому ⌘S спрашивает, куда его записать, и не может перезаписать ни одну из половин ([[topic:saving|Сохранение]]).
- **Объединение — один шаг отмены.** ⌘Z убирает добавленные байты *и* возвращает панель к тому файлу, из которого она была открыта.

## Дублирование: копия дампа как он есть

**Файл ▸ Дублировать** копирует содержимое панели в свободную панель новым несохранённым документом. Команда доступна в однофайловом режиме, где есть свободная панель.

Копия правится, а исходный файл остаётся открытым рядом, и сравнение показывает каждую правку как различие по мере набора. Сохранить можно любой из двух документов.
