# Разметка зон

> Разметить области незнакомого образа руками.

**Инструменты ▸ Разметка зон** — блокнот для диапазонов байтов. Выделите байты в дампе, дайте диапазону имя и цвет — и он будет нарисован зоной поверх hex-панели и на [[topic:minimap|миникарте]].

Он ничего не разбирает и не знает ни одного формата. Именно поэтому он полезен для образов, которые не читают остальные панели: прошивка EC, дамп контроллера батареи, незнакомый чип SPI Flash с платы, которую никто не документировал.

При ремонте это делают карандашом по распечатке. Здесь то же самое, только разметка хранится вместе с файлом: щёлкните строку зоны — дамп прокрутится к ней.

Зону можно и открыть [[topic:fragments|панелью фрагмента]] — отмеченные байты отдельным файлом, — это быстрый способ извлечь блок, опознанный на глаз.
